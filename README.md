# PortfolioMirror

An interactive, educational wealth-projection experience that compares a user's savings plan against disclosure-based portfolio proxies, classic allocations, and benchmarks.

## Features

- Inputs for age, capital, monthly contributions, contribution growth, inflation, fees, and one-time drawdowns
- Disclosure-based profile library with source links and clear approximation labels
- Side-by-side strategy comparison
- Nominal and inflation-adjusted projections
- Optimistic, median, and pessimistic scenarios
- Responsive, dependency-free interface
- Local scenario saving

## Important

PortfolioMirror is educational software, not investment advice. Public disclosures can be delayed, incomplete, range-based, and may not represent a person's full economic exposure. No trades are recommended or executed.

## Run locally

Open `index.html` in a modern browser.
